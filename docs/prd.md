# Rednote v1.0 产品需求文档（PRD）

| 项目 | 内容 |
| --- | --- |
| 产品名称 | Rednote（小红书课程项目） |
| 产品版本 | v1.0 |
| 文档状态 | 需求基线，供设计、开发与验收使用 |
| 更新日期 | 2026-10-18 |
| 产品形态 | Web 用户端与 Web 后台管理端，桌面端优先，适配手机 |
| 项目现状 | Spring Boot 初始化工程，尚无业务功能实现 |

## 1. 产品目标与范围

### 1.1 产品定位

面向课程学习和演示，构建一个以图文笔记为核心的内容社区，打通注册登录、内容发布、浏览搜索、点赞评论和后台用户管理的完整流程。用户能够分享生活内容、发现他人笔记并互动，管理员能够查看平台数据并管理账号状态。

首版成功标准是本文全部功能及验收场景通过，不以真实运营规模、推荐效果或商业转化为目标。

### 1.2 需求来源与默认值

**已确认的产品决策：**

- 课程 Web 项目，用户名与密码注册登录。
- 图文笔记必须包含标题、正文和 1–9 张图片，首图为封面；发布即公开。
- 首页和搜索按最新发布排序，搜索覆盖标题与正文。
- 两层评论，回复平铺在主评论下；仅能删除自己的内容，删除主评论同步删除其回复。
- 后台包含数据看板、用户查询、查看资料、禁用与启用，不含内容管理。

**v1.0 默认值：** 下文中的字段长度、图片类型与大小、分页大小、清理时限、看板时间范围、性能目标，以及未在上述决策中列出的细节均为本版默认规则，后续调整需同步更新对应需求与验收场景。

### 1.3 范围边界

本文所有编号需求均为首版必须交付项。首版不含原生 App、视频、草稿、私密笔记、发布审核、内容管理、关注、收藏、私信、通知、找回密码、推荐算法、评论点赞及账号删除。

PRD 定义产品行为、输入输出和验收条件，不规定数据库表结构、接口路径、文件存储供应商或前后端实现方式。现有工程技术依赖不等同于已实现能力。

## 2. 用户角色与权限

| 能力 | 游客 | 正常普通用户 | 管理员 |
| --- | --- | --- | --- |
| 浏览首页、搜索、公开主页和笔记详情 | 可以 | 可以 | 可以 |
| 发布笔记、上传图片、点赞、评论与回复 | 需登录 | 可以 | 与普通用户相同 |
| 修改个人资料、修改密码、退出登录 | 不适用 | 仅本人 | 仅本人 |
| 编辑与删除笔记、删除评论与回复 | 不可以 | 仅本人内容 | 仅本人内容 |
| 删除图片 | 不可以 | 仅本人且满足引用规则 | 仅本人且满足引用规则 |
| 进入后台、查看看板和用户资料 | 不可以 | 不可以 | 可以 |
| 禁用与启用普通用户 | 不可以 | 不可以 | 可以 |

- **PERM-01**：管理员通过预置方式创建，不提供管理员注册或公开角色切换入口；后台不得禁用管理员。
- **PERM-02**：被禁用账号的已有登录状态立即失效，禁止登录及所有需登录的写操作，仍可作为游客浏览公开页面；历史公开内容保留。
- **PERM-03**：所有权限均须在服务端校验，隐藏按钮不能替代权限校验。管理员身份不授予修改他人笔记、删除他人评论或图片的权限。

## 3. 页面与核心流程

### 3.1 页面清单

| 页面 | 核心内容与入口 |
| --- | --- |
| 首页 | 搜索入口、瀑布流、登录或个人入口、发布入口 |
| 注册页、登录页 | 账号表单、校验反馈、注册登录互相跳转 |
| 搜索结果页 | 关键词、笔记结果瀑布流、空结果和继续加载 |
| 笔记详情页 | 图片、标题、正文、作者、发布时间、点赞、评论及回复 |
| 发布与编辑页 | 标题、正文、图片上传、排序、移除、提交和取消 |
| 公开个人主页 | 头像、昵称、简介、已发布笔记分页；本人显示管理入口 |
| 个人设置页 | 修改昵称、头像、简介，修改密码，退出登录 |
| 后台数据看板 | 四项总量、最近 7 天趋势、刷新和统计时间 |
| 后台用户管理 | 搜索筛选、用户分页、资料详情、禁用与启用 |

### 3.2 核心流程

1. **注册与登录**：游客填写注册信息 → 校验 → 注册成功 → 登录页 → 登录成功进入首页。由受限操作触发登录时，成功后返回原页面，由用户继续操作，不自动提交先前写操作。
2. **发布笔记**：登录 → 输入标题正文 → 上传并排列图片 → 提交 → 成功进入详情页 → 首页与个人主页可见。
3. **浏览互动**：首页或搜索 → 笔记详情 → 点赞、评论或回复 → 展示最新状态；游客操作时引导登录。
4. **管理本人内容**：个人主页或详情 → 编辑并保存，或确认删除 → 列表和详情状态同步。
5. **管理账号**：管理员登录 → 后台用户管理 → 搜索并查看用户 → 确认禁用或启用 → 状态更新；禁用立即撤销该用户登录状态。

## 4. 功能需求

### 4.1 用户模块

| 编号 | 功能 | 业务规则与结果 |
| --- | --- | --- |
| USER-01 | 注册 | 用户名、密码、确认密码必填；用户名 4–20 位，仅字母、数字、下划线，忽略大小写判重；去除用户名首尾空格后校验。密码 8–32 位，至少包含一个英文字母和一个数字，不自动裁剪密码；两次密码须一致。成功创建普通用户并进入登录页，不自动登录。 |
| USER-02 | 登录 | 以用户名、密码登录，用户名大小写不敏感；账号或密码错误统一提示，禁用账号提示账号已禁用。成功后页面显示登录用户状态。 |
| USER-03 | 退出 | 清除当前会话并返回首页，刷新和返回原受限页面均不能恢复该会话权限。 |
| USER-04 | 修改资料 | 用户名只读；昵称必填，1–20 字；简介可空，最多 200 字；头像可选，未设置时使用默认头像。新账号昵称默认取用户名。昵称不要求唯一；保存成功后主页、笔记作者及评论作者展示最新资料。 |
| USER-05 | 修改密码 | 旧密码、新密码、确认新密码必填；验证旧密码，新密码须符合注册规则且不同于旧密码。成功后撤销该账号所有会话并跳转登录页，旧密码失效。 |
| USER-06 | 个人主页 | 公开显示头像、昵称、简介及有效笔记；不公开密码、账号状态等管理信息。笔记按发布时间倒序，每页 20 条，末页不足 20 条按实际展示；本人可进入编辑、删除和个人设置。 |

昵称、标题、正文、简介和评论先去除首尾空白再校验；长度按 Unicode 字符计数，中文和普通英文字母均各计一个字符。正文与评论保留内部换行，纯空白内容视为空。

### 4.2 笔记模块

| 编号 | 功能 | 业务规则与结果 |
| --- | --- | --- |
| NOTE-01 | 发布 | 标题 1–50 字、正文 1–5000 字、1–9 张已成功上传的图片均必填；图片有序且同一笔记内不重复，首张为封面。支持调整顺序和移除图片。成功后生成笔记，记录作者及发布时间，立即公开；提交过程中禁止重复点击。 |
| NOTE-02 | 查询详情 | 展示全部图片、标题、正文、作者头像昵称、发布时间、点赞数量及本人点赞状态、评论总数和评论区。图片按发布顺序查看，评论总数包含回复。游客不显示个人点赞选中状态。 |
| NOTE-03 | 编辑 | 仅作者可进入并提交；回填现有内容，允许修改标题、正文、图片及顺序，规则同发布；保存成功后整体生效，保留原发布时间，记录更新时间。取消或保存失败时，已发布版本及原有图片保持不变。 |
| NOTE-04 | 删除 | 仅作者可删除，弹窗确认；成功后从首页、搜索、个人主页移除，详情不可访问，相关点赞、主评论和回复同步失效并退出有效计数。图片按 FILE-03 解除引用，不直接无条件删除物理文件。 |

不存在或已删除的笔记统一显示“笔记不存在或已删除”。删除与互动并发时，删除完成后不得留下可见互动或有效计数；对已删除内容的后续操作失败并提示刷新。编辑页面有未保存修改时，离开或取消需确认放弃。

### 4.3 文件服务器

| 编号 | 功能 | 业务规则与结果 |
| --- | --- | --- |
| FILE-01 | 上传图片 | 需登录；头像和笔记均支持 JPEG、PNG、WebP，单张最大 10 MB（10 × 1024 × 1024 字节，含边界）。服务端校验实际文件类型与图片可解码性，拒绝伪造扩展名及损坏文件；返回可预览图片的标识和访问地址。文件名不能决定服务端存储路径。 |
| FILE-02 | 使用图片 | 仅可关联本人上传的图片；上传成功后显示预览。笔记图片加载失败显示占位与重试入口；公开内容引用的图片允许游客访问。新头像保存成功后才替换原头像引用。 |
| FILE-03 | 删除与引用保护 | 仅上传者可删除无引用图片；删除仍被任一有效笔记或头像引用的文件须拒绝。移除笔记图片或删除笔记时，仅在业务保存成功后解除对应引用；共享文件有其他引用时继续可用。 |
| FILE-04 | 无引用清理 | 上传后未使用的图片，从上传成功起计时；曾被引用的图片，从最后一个有效引用解除时计时。连续无引用满 24 小时后进入清理，清理任务至少每小时执行一次，原则上在满 25 小时前删除；清理前再次确认无引用。取消编辑产生的新图片适用该规则。 |

单张上传失败可独立重试，不清空其他已上传图片；仍在上传或存在失败且未移除的图片时，不允许提交笔记。图片上传成功不等于笔记已发布。文件访问安全不依赖原文件名或地址难以猜测。

### 4.4 首页与搜索

| 编号 | 功能 | 业务规则与结果 |
| --- | --- | --- |
| HOME-01 | 瀑布流 | 游客可访问；卡片展示封面、标题、作者头像昵称、点赞数及登录用户本人点赞状态，点击卡片进入详情，点击作者进入公开主页。按发布时间倒序、笔记 ID 倒序稳定排序，每批 20 条，滚动加载并对同一笔记去重。 |
| HOME-02 | 搜索 | 对标题和正文进行关键词包含匹配，英文字母匹配不区分大小写；关键词作为普通文本处理。去除首尾空格，最多 100 字；空关键词返回首页列表；超长时提示修改，不自动截断。结果排序与每批大小同首页。 |
| HOME-03 | 列表状态 | 首次加载、追加加载、加载失败可重试、空列表、空搜索结果和全部加载完毕均有明确反馈。更换关键词清空旧结果并从首批加载；滚动加载期间新发布笔记在刷新后出现。 |

### 4.5 点赞模块

| 编号 | 功能 | 业务规则与结果 |
| --- | --- | --- |
| LIKE-01 | 点赞 | 登录用户可点赞任意有效笔记，包括本人笔记；每人每篇最多一个有效点赞。重复请求不新增记录或重复计数，成功后列表与详情数量及状态一致。 |
| LIKE-02 | 取消点赞 | 仅取消本人点赞；重复取消保持未点赞状态，计数不为负；取消后可重新点赞。操作失败提示并恢复至服务端确认状态。 |

### 4.6 评论模块

| 编号 | 功能 | 业务规则与结果 |
| --- | --- | --- |
| COMMENT-01 | 增加主评论 | 登录用户对有效笔记发表评论，1–500 字纯文本；成功后显示作者、内容和时间，更新总数，提交成功才清空输入。主评论按创建时间倒序、ID 倒序，每页 20 条。 |
| COMMENT-02 | 回复 | 登录用户可回复主评论或其中具体回复，也可回复本人；回复统一归属主评论并平铺展示，不产生第三层。展示回复作者及被回复用户昵称；按创建时间正序、ID 正序，每页 20 条。 |
| COMMENT-03 | 删除主评论 | 仅评论作者可删除，需确认；删除该主评论和所有关联回复，即使回复由他人发表，也同步移除并扣减有效评论总数。笔记作者无额外删除权限。 |
| COMMENT-04 | 删除回复 | 仅回复作者可删除，需确认；仅移除该条回复，不连带删除其他回复。其他回复若指向已删除回复，保留被回复用户展示，但不再提供跳转该回复的入口。 |

回复目标或所属主评论在提交前已被删除时，提交失败，保留输入并提示刷新；不自动改成回复其他对象。重复点击提交期间禁用按钮；网络结果不明确时先刷新确认，避免自动重复发布。空评论区显示引导，回复可按需展开加载。

### 4.7 后台管理

| 编号 | 功能 | 业务规则与结果 |
| --- | --- | --- |
| ADMIN-01 | 后台访问 | 仅管理员可访问页面及数据；普通用户直接请求后台资源也须拒绝。管理员登录后提供后台入口。 |
| ADMIN-02 | 用户列表与详情 | 每页 20 条，注册时间倒序、用户 ID 倒序。用户名和昵称分别支持包含查询，忽略英文大小写，状态支持全部、正常、禁用，多个条件取交集。列表展示用户 ID、用户名、昵称、头像、角色、状态和注册时间；详情补充简介、有效笔记数。不得展示密码或密码摘要。 |
| ADMIN-03 | 禁用与启用 | 仅允许操作普通用户，每次操作需确认。重复禁用或启用不产生额外副作用；成功后更新列表状态。禁用立即撤销所有已有会话，后续请求无法继续写入；启用不恢复旧会话，用户需重新登录。历史笔记、点赞与评论继续公开并参与统计。 |
| ADMIN-04 | 数据看板 | 展示下表指标及最近 7 天趋势，页面打开或手动刷新时读取最新数据，不要求自动轮询；展示统计时间，失败时可重试。 |

看板统计口径：

| 指标 | 口径 |
| --- | --- |
| 注册用户总量 | 普通用户账号总数，含禁用账号，不含预置管理员 |
| 有效笔记总量 | 未删除笔记数量，包含禁用账号已发布的笔记 |
| 有效点赞总量 | 未取消且关联有效笔记的点赞数量 |
| 有效评论总量 | 未删除且关联有效笔记的主评论与回复数量之和 |
| 每日新增用户 | 当日注册的普通用户，后续禁用不改变历史新增数 |
| 每日发布笔记 | 当日成功发布的笔记，后续编辑、删除不改变历史发布数 |

所有日期以北京时间（Asia/Shanghai）计算，每日区间为当日 00:00:00（含）至次日 00:00:00（不含）。最近 7 天包含今天和此前 6 个自然日，无数据日期补零；今天为截至统计时间的累计值。总量与趋势允许因删除产生口径差异，界面应提供指标说明。

## 5. 异常状态与交互约定

| 编号 | 场景 | 预期行为 |
| --- | --- | --- |
| UX-01 | 未登录或登录过期 | 浏览公开内容不受影响；写操作提示登录并引导跳转，不自动补发写请求。表单因认证失败不能保存时保留当前页面输入，离开前提示。 |
| UX-02 | 无权限 | 明确提示无权限；不泄露私有管理数据，不执行操作。 |
| UX-03 | 目标不存在或已删除 | 展示内容不可用状态，并提供返回首页或列表入口。 |
| UX-04 | 表单不合法 | 在对应字段展示原因；前后端采用一致约束，修正前不能成功提交。 |
| UX-05 | 网络或服务失败 | 提示失败与重试；保留输入和已成功上传预览，避免成功提示或虚假计数。结果未知时提示先刷新确认，不自动重发发布、评论等创建操作。 |
| UX-06 | 空态与加载 | 区分加载中、无内容、无搜索结果与已加载全部；失败不能伪装为空结果。 |
| UX-07 | 删除及账号状态变更 | 明确操作对象与影响，确认后执行，取消无副作用；主评论删除需提示回复也将删除。 |

## 6. 非功能需求

| 编号 | 要求 | 验收标准 |
| --- | --- | --- |
| NFR-01 | 安全 | 密码以不可逆的安全密码摘要存储，不明文保存、返回或记录日志；服务端验证身份、角色和资源归属；用户文本安全展示，不执行 HTML 或脚本；对基于会话的写请求防护跨站请求伪造。 |
| NFR-02 | 一致性 | 笔记保存整体成功或失败；权限、点赞唯一性、评论级联失效和图片引用保护在并发下仍成立；客户端状态最终以服务端确认结果为准。 |
| NFR-03 | 查询性能 | 在固定测试环境、1 万篇有效笔记、20 个并发用户及有代表性的点赞评论数据下，首页、搜索、个人主页、详情等常规查询的 P95 服务端响应不超过 1 秒，不含图片传输。记录硬件、数据分布、预热方式及测试结果；稳定负载持续至少 5 分钟。 |
| NFR-04 | 终端适配 | 验证验收时桌面 Chrome 稳定版，至少覆盖 1440 px 桌面宽度和 375 px 手机宽度；无页面级横向溢出，核心按钮、表单和弹窗可用；手机后台表格可在表格区域横向滚动。 |
| NFR-05 | 可维护性 | 业务错误具有可识别原因；服务端记录排障所需操作结果和错误，日志不包含密码等敏感信息。文件清理失败可重试且不误删有效引用文件。 |

## 7. 验收场景

准备普通用户 A、B、管理员 M、禁用用户 D；准备正常图片、边界大小图片、超限文件和伪造图片。以下场景均为首版发布门槛。

| 用例 | 关联需求 | 操作与预期结果 |
| --- | --- | --- |
| AC-01 | USER-01 | 使用合法字段注册成功并进入登录页；以仅大小写不同的用户名再次注册失败；用户名和密码长度边界、缺少字母或数字、确认密码不一致均按规则校验。 |
| AC-02 | USER-02/03、UX-01 | 正确密码登录成功，错误密码失败；退出后重用原会话写入失败；游客可浏览并在点赞时进入登录流程，登录后不自动点赞。 |
| AC-03 | USER-04/06 | 修改昵称、头像和简介后，主页、笔记和评论作者信息更新；用户名不可修改；访客看不到管理字段；新账号使用默认昵称和头像。 |
| AC-04 | USER-05 | 旧密码错误或新密码不合法时不修改；成功后所有会话失效，旧密码无法登录，新密码可登录。 |
| AC-05 | NOTE-01、FILE-01 | 1 张和 9 张合法图片可发布，首图为封面；无图、超过 9 张、纯空白正文、标题正文超长及上传未完成时不能发布。提交期间重复点击仅产生一篇笔记。 |
| AC-06 | NOTE-02/03 | A 编辑自己的笔记后内容整体更新，原发布时间保持；取消或保存失败不改变已发布版本；B 直接请求修改 A 的笔记失败。 |
| AC-07 | NOTE-04、UX-07 | 删除确认取消时无变化；确认后各列表移除，原详情不可访问，点赞和评论失效；B 无法删除 A 的笔记；删除完成后并发互动不能留下有效数据。 |
| AC-08 | HOME-01/03、USER-06 | 准备超过 40 篇笔记及相同发布时间数据，验证首页分批加载、稳定排序与去重，个人主页每页 20 条且仅展示该作者笔记；空列表、末页和重试状态正确。 |
| AC-09 | HOME-02 | 分别用标题词和正文词搜索成功；验证英文大小写、首尾空格、空词、100 字边界、超长和无结果；切换关键词不会混入旧结果。 |
| AC-10 | LIKE-01/02 | A 连续或并发点赞同一篇笔记仅增加 1，重复取消不产生负数，重新点赞成功；A 可赞自己的笔记，列表和详情状态一致。 |
| AC-11 | COMMENT-01/02 | 评论和回复接受 1–500 字，拒绝空白及超长；主评论最新优先、回复最早优先，各超过 20 条时分页正确；回复具体回复仍为两层并展示被回复用户。 |
| AC-12 | COMMENT-03/04 | A 删除自己的主评论时，B 的关联回复一并移除并准确扣减总数；删除某条回复不删除其他回复；他人及笔记作者不能删除非本人内容。 |
| AC-13 | COMMENT-02/04、UX-05 | 回复目标提交前被删除时操作失败且保留输入；已存在的其他回复仍显示被回复用户；模拟提交结果未知时不自动重复创建。 |
| AC-14 | FILE-01/02 | JPEG、PNG、WebP 上传预览成功；恰好 10 MB 可通过，超出失败；伪造扩展名、损坏图片被拒绝；单张失败不清空其他图片，B 无法关联 A 上传的图片。 |
| AC-15 | FILE-03/04 | 编辑移除图片在保存后才解除引用，取消保留原图；删除仍有引用的文件被拒绝，删一篇共享图片笔记不影响另一篇；模拟时间推进验证无引用 24 小时后清理、重新引用后不会误删。 |
| AC-16 | PERM-01/03、ADMIN-01 | 游客和普通用户无法访问后台页面及数据；管理员可进入；无管理员公开注册入口，管理员不能被禁用，也不能凭管理员身份删除他人内容。 |
| AC-17 | ADMIN-02/03、PERM-02 | 验证用户查询条件交集、分页和敏感字段不返回；禁用 A 后其多个已登录会话均无法写入或重新登录，但公开内容保留；启用后旧会话不恢复，新登录成功；重复状态操作无副作用。 |
| AC-18 | ADMIN-04 | 用固定数据核对四项总量；取消点赞、删除主评论及笔记后有效数正确；禁用用户不改变历史公开数据统计，管理员不计入注册用户数。 |
| AC-19 | ADMIN-04 | 验证北京时间午夜前后数据归属、7 天含今天、无数据补零；删除笔记降低有效总量但不改历史发布数；手动刷新更新统计时间与数据。 |
| AC-20 | UX-01～07、NFR-01/04 | 模拟未登录、过期、越权、资源删除、网络和上传失败，验证反馈及输入保留；脚本文本不执行；桌面和手机宽度下完成注册、发布、搜索、互动及后台管理。 |
| AC-21 | NFR-02/03/05 | 完成并发点赞、禁用后写入、删除与回复、清理与重新引用的竞争场景；按规定负载测量查询 P95；清理失败重试不会误删引用图片，日志不泄露密码。 |
