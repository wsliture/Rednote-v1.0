# Rednote 界面原型

原生 HTML / CSS / JavaScript 双端高保真原型，无需安装依赖或启动 Spring Boot。

## 启动

在项目根目录执行：

```sh
python3 -m http.server 8765 --directory docs/prototype
```

- 用户端：[http://localhost:8765](http://localhost:8765)
- 后台入口：[http://localhost:8765/admin.html](http://localhost:8765/admin.html)

请通过本地 HTTP 服务访问；拆分后的导航需要读取独立 HTML，不支持双击文件的 `file://` 预览。预置图片已全部保存到 `images/`，无需联网加载。旧版浏览器缓存中的预置图片地址会自动迁移到本地路径，保留已有演示数据。

## 演示方式

默认游客。右下角「原型演示」独立于产品导航，可以切换身份、异常状态和重置数据。后台需先选择管理员，再访问后台入口。禁用用户不可登录，但可作为游客浏览。

演示账号用户名：linxia、mumu、yuchen、admin；初始密码均为 `Demo1234`
。这些仅是公开的虚拟原型数据，不是真实服务凭据。新注册及修改后的密码只在当前页面内存保留，刷新后恢复演示密码，密码不写入本地存储。

资料、发布内容、评论、点赞与用户状态保存于当前来源的 localStorage；身份保存在
sessionStorage。重置会清除本地业务改动。大图片可能超过浏览器存储配额，此时提示仅本次会话保留。

## 页面索引与需求覆盖

| 页面 / 路由                | 演示能力                         | 对应 PRD                   |
|------------------------|------------------------------|--------------------------|
| `#/`                   | 20 条分批瀑布流、滚动加载、点赞、作者入口       | HOME-01/03、LIKE-01/02    |
| `#/search?q=关键词`       | 标题正文搜索、空结果、关键词长度提示           | HOME-02                  |
| `#/login`、`#/register` | 校验、模拟登录、注册、登录后返回原页           | USER-01/02、UX-01/04      |
| `#/note/1`             | 图片切换、正文、点赞、两层评论及分页、删除确认      | NOTE-02/04、COMMENT-01～04 |
| `#/publish`、`#/edit/1` | 本地图片校验预览、排序、移除、失败重试、预览、未保存确认 | NOTE-01/03、FILE-01/02    |
| `#/profile/1`          | 公开资料、本人管理入口、每页 20 条笔记        | USER-06                  |
| `#/settings`           | 资料、头像、密码、退出，修改作者信息同步         | USER-03～05               |
| `#/admin`              | 四项总量、固定七天演示趋势、口径、刷新          | ADMIN-01/04              |
| `#/admin/users`        | 交集筛选、分页、资料抽屉、禁用启用确认          | ADMIN-02/03              |
| 演示面板                   | 游客、普通用户、管理员、禁用账号及异常状态        | PERM-01～03、UX-01～07      |

加载中、空态、网络错误适用于列表和看板。网络错误也可在表单中模拟保存失败；在发布表单打开演示面板切换状态不会清空草稿。选择图片上传失败后再添加图片，可独立重试。提交结果未知保留表单并提示先确认结果。过期状态保留编辑表单，不自动补发。

## 设计与文件组织

- 11 个独立 HTML：保留 `index.html` / `admin.html` 两端入口；新增搜索、详情、发布、编辑、登录、注册、个人主页、设置与后台用户管理页面。每页都有完整布局和所需模板。
- `styles.css`：共享视觉规范与响应式样式；白底、#ff2442 强调色、系统中文字体、圆角与轻量边框。
- `data.js`：44 篇生活方式笔记、5 个演示账号与示例评论。
- `images/`：11 张去重后的 JPEG 素材，供笔记封面、详情、登录背景及后续上传测试共用；`manifest.json` 记录来源、文件大小与尺寸。
- `app.js`：只负责启动。
- `js/store.js`：模拟数据读取、保存、身份与运行时状态；沿用原有浏览器存储键。
- `js/ui.js`：模板克隆、数据绑定、导航外壳绑定、弹窗、图片失败反馈和演示面板。
- `js/navigation.js`：兼容旧 Hash 路由，加载独立 HTML 的结构并调用页面脚本；不执行载入 HTML 的 script。
- `js/pages/`：按首页/个人主页、笔记评论、登录注册、发布编辑、设置与后台分离数据绑定及业务交互。
- `js/events.js`：一次性公共事件委托，并分发给业务页面。
- [MIGRATION.md](MIGRATION.md)：逐页数据与表单说明、权限条件及 Thymeleaf 迁移对应表。
- `tests/smoke.cjs`：可重复运行的浏览器回归脚本。

重复卡片、评论、回复、图片和用户表格行都在 HTML `<template>` 中。脚本通过 DOM 属性、`textContent`、`value` 填充，不再拼接整页 HTML。各页仅携带自己使用的模板。公共外壳暂在各 HTML 保留完整副本，并以注释标记未来片段抽取位置。

独立页面及参数详见 [迁移指南的页面索引](MIGRATION.md#页面与视图数据)。例如 `note.html?id=1`、`search.html?q=生活` 可直接访问；旧的 `index.html#/note/1` 仍可使用。

桌面用户端侧边导航，手机底部导航与双列瀑布流；详情手机纵向排列。后台手机折叠菜单，表格区域独立横向滚动。弹窗支持
Escape、焦点循环与关闭后焦点恢复。

## 实现边界

本原型不连接后端，不构成 PRD 全业务验收：权限切换与限制只在浏览器模拟，不能作为安全防护；文件类型与可解码性为客户端检查，不包含服务端内容嗅探、物理存储、共享引用保护或
24 小时清理。真实会话撤销、并发一致性、CSRF、密码摘要、数据库分页与性能验收均待后端实现。

看板总量基于本地数据计算；趋势是固定日期的示例事件数据，不随本地新增或删除回算。时间标注使用北京时间。发布和评论模拟操作仅改变本地数据；刷新或身份切换不会自动重发写操作。

未加入关注、收藏、私信、通知、审核或后台内容管理。

## 本次重构验证

使用本机 Microsoft Edge（Chromium）无头浏览器回归两端业务流程及 11 个页面 × 1440、768、375px 的响应式场景。结果详见 [VERIFICATION.md](VERIFICATION.md)。截图对比使用同一数据、身份和固定视口，未修改产品设计。

可选：在已有 Playwright 和浏览器的环境，从项目根目录运行：

```sh
node docs/prototype/tests/smoke.cjs
```

若 Playwright 不在默认模块搜索路径，可使用环境的 `NODE_PATH`；若使用系统浏览器，可设置 `REDNOTE_BROWSER_PATH` 指定可执行文件。自定义预览地址使用 `REDNOTE_PROTOTYPE_URL`。测试使用独立临时浏览器上下文，不更改日常浏览器中的演示数据。原型运行本身不需要 Playwright。

尚未完成 Chrome 稳定版实机、真实移动设备及 PRD 后端/性能验收。

## 本地图片测试素材

所有预置图片都在 `images/`，保留原始素材 ID 作为文件名，方便对应和复用。同一素材在多篇笔记及登录背景中共用，不重复保存。图片统一下载为宽度 1000px 的 JPEG；可直接在发布页或头像设置中选择这些文件进行正常上传、预览、排序、9 张上限及重复图片检查。图片尺寸和字节大小见 [素材清单](images/manifest.json)。这些是正常图片，不包含损坏文件、伪造类型或 10 MB 边界测试文件。
