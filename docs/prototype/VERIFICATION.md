# HTML 结构重构验证记录

验证日期：2026-10-18。范围：原型结构重构，不包含真实后端验收。

## 环境与方法

使用本机 Microsoft Edge（Chromium）及 Playwright，无头模式，独立浏览器上下文。重构前保留旧脚本和页面截图；以旧版原型与新版原型分别启动本地 HTTP 服务，固定相同模拟数据、身份及 1000px 视口高度进行对照。桌面宽度为 1440px，中间宽度为 768px，手机宽度为 375px。

截图对比屏蔽看板统计时间这一动态文本；其余内容不做屏蔽。按 RGB 通道差值大于 25 的像素计算差异比例，另检查 DOM 横向溢出和脚本错误。固定视口对照避免浏览器连续缩放的截图残影。

## 功能回归

`tests/smoke.cjs` 已通过：

- 首页初始 20 条、搜索、点赞及登录返回原页；登录成功不会自动补发点赞。
- 图片切换、主评论、具体回复和删除主评论时关联回复同步移除。
- 发布、预览、编辑保存、删除及个人主页同步；未保存离开确认取消后保留原表单。
- 本地图片选择、模拟失败、阻止失败图片发布、单图重试、封面排序与移除；提交结果未知时保留输入。
- 资料修改、密码修改后跳转登录、使用新密码登录；新注册后不自动登录，内存中的新密码在轻量导航后仍然有效。
- 非管理员访问后台拒绝、管理员看板、查询筛选、资料抽屉、禁用/启用状态更新。
- 加载、空态、网络失败、过期草稿保留、已删除笔记反馈。
- 冷加载 HTML 失败保留当前 DOM 和输入，重试成功；快速跳转最终挂载最后一次请求页面；前进/后退可用。
- 旧版 localStorage 自定义内容保留，预置远程图片地址迁移为本地地址。
- 11 个 HTML 独立入口 × 三种宽度，共 33 个响应式场景，无页面级横向溢出。
- 操作过程中无 JavaScript 运行时错误，无外部图片或脚本请求。一次点击仅改变一次点赞计数，未发生重复事件绑定。

全部原型脚本通过 `node --check`。页面脚本中已无 `innerHTML` / `insertAdjacentHTML` / `document.write`，动态文本通过 DOM API 赋值。

## 复现方式与限制

启动原型后，从项目根目录运行 `node docs/prototype/tests/smoke.cjs`，需要外部提供 Playwright 及浏览器。可用 `REDNOTE_BROWSER_PATH` 指定系统 Chromium 浏览器、`REDNOTE_PROTOTYPE_URL` 指定测试地址。

本次未启动 Spring Boot、未修改业务 Java 代码或真实接口，未执行真实认证、安全、并发、图片服务与性能验收；Chrome 稳定版实机和真实移动设备验收仍待正式开发阶段完成。
