- 回复平铺、根评论级联删除、已删除回复目标拒绝。
- 删除笔记不改写历史发布趋势。
- 禁用及改密后的旧会话失效、登录失败保留返回地址、外部返回地址拒绝。

`tests/browser/smoke.cjs` 通过：

逐页截图保存于构建产物目录 `target/frontend-verification/`，浏览器执行日志为该目录中的 `browser.log`。视觉检查以原型的布局、颜色、字号、瀑布流断点和公共组件为依据；统计、时间、点赞数及用户操作数据由预览服务生成。

## 复现

启动 preview 后，使用外部 Playwright 环境运行：

```sh
mkdir -p target/frontend-verification
NODE_PATH=/path/to/node_modules \
REDNOTE_URL=http://localhost:8080 \
REDNOTE_BROWSER_PATH="/path/to/chromium" \
REDNOTE_SCREENSHOTS=target/frontend-verification \
node tests/browser/smoke.cjs
```

启动说明及全部接口见 [frontend.md](frontend.md)。
